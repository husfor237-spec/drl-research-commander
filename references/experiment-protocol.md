# 实验闸门协议

## 共同规则

项目材料统一位于项目 `.codex-run/drl-research/`。主帅维护 `state.md` 与 `control.json`，登记阶段判定、预算授权、冻结版本、所有权和证据索引；角色只写任务书指定的报告/实现/运行产物。标准任务接口采用 `references/templates.md`；具体文件名由任务书指定，以下产物名称表示用途，不强加与模板冲突的路径。

各角色只读 `SKILL.md`、本角色规范、具体任务与必要证据。主帅把本协议中与任务有关的验收条目放入任务书，不要求角色预加载全部角色文档。

所提方法及训练路径禁止模仿、专家示范、教师监督、启发式暖启动、物理引导网络或损失、人工调度优先级、额外奖励塑形。允许真实物理环境、原始目标、传统基线和只排除非法动作且不优化业务目标的可行性处理；传统基线不得成为候选训练的教师或暖启动来源。环境、信息与指标必须从需求确定，不刻意偏向自己的方法。

组合与弱创新允许，论断须匹配证据。原文报告、本地复现、推断分别标注；文献证据带原文页/节/公式/表位置，本地证据带运行 ID 和绝对路径，未知不补造。过关判断实验的有效性，不要求新方法获胜。

## 闸门登记与修订

阶段 ID 和名称固定为下表。每次判定记录产物绝对路径/版本、检查证据、结论（通过/需修正/证据不足）、阻塞项、获准的下一步、剩余预算和负责人。仅计划、摘要或“应该正常”不能充当完成证据。

未通过时停下依赖该闸门的工作，保留失败产物，执行获准的补证/定位任务。已通过的环境、基线、建模或协议发生实质变更时，登记新版本及影响范围，重开受影响闸门；旧版本、旧结果和失败记录保留。主帅不能仅改状态字段使失败变成通过。

正式实验前预算、种子、调参范围、场景划分和统计方法必须冻结。G3/G4 存在未解释失败时不得大规模跑；经授权的小规模诊断可进行。预算、所有权与运行保护在所有运行阶段生效。

## G0–G9 产物、通行标准与失败动作

| 阶段 ID 与名称 | 必需产物 | 通行标准 | 失败时动作 |
| --- | --- | --- | --- |
| **G0 需求授权算力预算** | 需求/原始目标、方法禁区、数据/信息边界、项目路径与角色写入范围、算力/时间/并发/费用预算、停止条件及授权记录 | 问题和验收可执行；预算及运行权限已明确；可用资源与依赖已核实；未授权事项明确排除 | 补齐需求/资源/授权，缩小到已授权范围；不启动训练、不假定无限预算 |
| **G1 文献调查** | 有版本与来源的原文索引、差异矩阵、含公式变量与信息假设的建模提取、算法组件、仿真/数据、原文结果及复现缺口 | 关键主张可定位到原文；报告/复现/推断分开；未知和受禁组件已标注；足以支撑主线选择或有明确缩小后的范围 | 补原文/补证、缩小论断或候选；关键缺口未解决不得以猜测冻结主线 |
| **G2 主线与建模冻结** | 主线/备选与可证伪假设、创新强度、目标/约束/转移公式和变量单位、观测时序、算法训练路径、环境与基线验收规格、冻结版本 | 路径符合禁区；信息因果顺序明确；可实现且可验收；环境未迎合方法；假设、范围和差异有证据 | 回到 G1 补证或修改模型/主线并重新冻结；未决歧义不交给实现者暗选 |
| **G3 环境验证** | 环境实现与版本、最小可手算实例、事件轨迹、时间/边界/守恒/约束/泄漏检查、种子回放和失败清单 | 实际结果符合冻结规格；原始目标与指标对齐；关键检查通过，所有失败已定位并修复或经证据说明为预定义预期行为；没有未解释失败 | 保留失败，最小化定位并修复；若假设变更重开 G2；停止大规模训练 |
| **G4 基线复现** | 基线来源/版本/配置、原文结果与本地重复运行、口径/预算对齐、差异解释、运行证据与成本/违例 | 基线实现和目标/信息/约束符合规格；按事先标准验收，差距可解释且不导致比较失真；所有失败有证据解释 | 定位实现/环境/参数/依赖；需要改变标准时新版本重验；无法复现则声明限制、更换合理基线并冻结依据；停止大规模跑 |
| **G5 最小方案及小规模试验** | 最小组件实现、已授权小预算与种子、小规模运行/失败证据、成本估计、假设初检及继续/停止建议 | 训练与评价路径合规且可复现；实现确实检验指定假设；预算可支撑正式设计，异常已解释；负结果也可通过 | 修复实现或调整假设后按小预算重试；主线变化重开 G2，环境/基线变化重开相应闸门；无依据时停止路线 |
| **G6 正式实验设计冻结** | 下文规定的完整协议、配置/代码/环境/数据版本或哈希、预算分配、统计与选择规则、冻结时间和版本 | 主帅核对设计完整、可执行；测试用于评价且未用于选择；主实验/消融/泛化能够检验论断；资源和运行保护就绪 | 补齐设计、减少范围或取得预算授权后重新冻结；不先跑正式评价再补协议 |
| **G7 主实验消融泛化** | 按冻结协议执行的多次运行、原始指标/日志/检查点、主实验/消融/泛化结果、失败与违例、统计不确定性和成本、偏差清单 | 所有计划项完成或依预设停止规则处理；运行可追溯，统计可重算；偏差得到解释和处理；结论允许不优于基线 | 保留失败和偏差，按预设规则修复/重跑；设计改变回 G6，环境/基线改变重开 G3/G4；测试反馈选方案需新的独立评价 |
| **G8 独立审查** | 真实独立审查任务/身份、冻结输入及实际检查范围、问题证据、可复核修正与复核报告 | 审查只据产物和冻结规格；未接受主帅辩护；阻塞问题已修正并复核，缺证与审查限制已披露 | 追加原始证据或修正后独立复核；受影响闸门重开；独立审查无法完成则保持未完成，不能用自查冒充 |
| **G9 论文结论** | 论断—证据对应表、最终公式/设置/结果/成本/违例与限制、原文定位与复现索引、论文版本及审查处理记录 | 每条论断受实际证据支持，创新表述不过度；负结果/未知/限制可见；指标能追溯至原始运行，阻塞审查项已关闭 | 降低或撤回无证据论断、补充获准实验并重开相关闸门；不删失败、不补造结果、不为投稿措辞宣布成功 |

G4 若没有可对齐的原文数值，不能声称已复现论文性能；可冻结为“独立实现基线”，但需来源核对、可算实例、实现验证和公平性依据。协议、后续图表与论文均保留此限制。

G2/G6 冻结比较设计、G8 派发审查前，用 [常见陷阱](pitfalls.md) 做自查与审查索引；命中不等于违规，须先取证再判定，取证不到记未知。G9 的论断—证据表按 [项目模板](templates.md) 提供的资产逐条填写，每条追到运行 ID 与绝对路径。

## G6 冻结清单

正式训练和测试评价前，保存不可覆盖的协议版本与配置摘要，至少包含：

1. **对象与版本**：研究假设、方法/基线/消融定义、代码及未提交改动快照、环境/依赖、数据与场景生成器版本或哈希、原始目标与信息访问规则。
2. **划分与场景**：训练/验证/测试划分单位、数据与场景 ID/生成种子、隔离方法、场景规模/负载/资源/分布、泛化范围；禁止事后仅保留有利场景。
3. **种子与重复**：训练、环境、评价种子列表或确定性生成规则，独立训练次数、每模型评价次数、方法间配对规则。预先区分独立训练与同一模型的重复评价。
4. **调参与选择**：每种方法的搜索范围/试验数/预算、验证指标、模型/checkpoint 选择规则、平局规则及停止条件。传统基线的调参资源也公开。测试集不能参与选择。
5. **统计**：主次指标、单位/方向、原始目标的计算与聚合、独立样本单位、均值/中位数等汇总、效应量、区间或其他不确定性估计、配对/层级分析及适用假设、多重比较处理。无假设检验时说明依据，不能事后择优换统计方法。
6. **失败与约束**：超时/崩溃/数值异常/缺失结果的计入规则、重试上限和预算归属、违例定义/分母/严重程度与可行率；失败不等同于可删除的缺失值。
7. **成本与执行**：每运行及总步数/时间/算力/费用、设备/并发、训练与推理成本口径、检查点和监控频率、资源停止规则、唯一 ID、所有权、恢复与交接方式。

重复次数和统计方法按不确定性需求与预算确定，不预设固定通用次数。若预算不足以支撑某类论断，冻结时缩小论断，不能实验结束后隐藏不确定性。G5 已查看的实例不可继续声称为未见测试。

冻结变更必须记录原因、差异、已访问测试信息、受影响运行、额外预算和重验计划。技术故障若未改变协议，可按预设重试规则执行；改变候选/参数/数据/统计选择须新版本。测试反馈驱动的选择须新的独立测试安排；无可用独立测试时降级结论并披露探索性结果。

## 运行、恢复与证据

- 执行者提交运行记录与配置，由实际持有调度所有权的主帅会话通过 `project_control.py claim-run` 登记运行，并通过 `assert-owner` 验证后调度；执行子代理不得冒用主帅身份。参数以项目脚本真实接口及任务书为准；失败/缺失时不得绕过保护。启动、续跑、重试和调度变更前复验所有权。
- 每运行保存唯一 ID、尝试/续跑关系、配置与种子、代码/环境/依赖/数据版本、命令、日志、原始指标、检查点、状态、失败、违例与成本。新独立运行用新 ID；完成/失败的终态运行不得重启，需要恢复时用新调度运行 ID 引用旧运行与检查点，保留逻辑训练链；续跑不增加独立样本数。
- 长训练持久化作业/进程 ID、所有权、进度、资源消耗、最后检查点、恢复所需训练/随机/回放状态、依赖和命令。模型上下文压缩只触发读交接与检查现有作业，不触发重启训练。
- 所有方法共享对应实验条件；方法特有计算/信息差异公开。禁止以更少搜索的基线或被删失败的候选进行隐性不公平比较。
- 原始多次运行、失败、违例和冻结版本持续保留。更正指标另存版本并说明计算差异；聚合表引用全部纳入和排除的运行及预设理由。

本协议规定后续论文实验的执行条件；编写或安装 skill 本身不授权启动真实论文实验。角色对话仅给简短结论、阻塞项和产物绝对路径，完整材料落盘。
