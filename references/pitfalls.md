# 常见陷阱与不公平比较清单

按需读取：主帅在 G2/G6 冻结前、G8 派发前读一遍；分析者与审查者用它做自查/审查索引。每条给出**现象 → 为什么是问题 → 可复核动作**。命中不等于违规：先取证，再判定；无法取证时写未知。

本清单不新增禁令，只是把 `SKILL.md` 的共同规则落到可检查的动作上。

## 一、信息泄漏

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 归一化/标准化统计量在训练+验证+测试全部数据上一次性拟合 | 测试集信息进入观测生成过程 | 检查归一化器拟合范围与拟合时刻，是否只用了训练段；泄漏时重跑 |
| 策略观测含未来信息（未来任务到达、未来碳强度、未来队列长度） | 决策时刻不可得，等于给候选开天眼 | 逐字段列出"该字段在决策时刻何时可获得"，对照事件时间线 |
| 用测试集选超参 / 早停 / 选 checkpoint | 测试集参与了选择，评价不再独立 | 查选择规则与实际访问记录；命中则需新的独立测试安排 |
| 观测里混入优化器状态、损失值、梯度范数、episode 编号等训练内部量 | 推理时不存在，属训练期特权信息 | 对照推理路径实际输入字段 |
| 用全局状态（全网队列、全网任务表）替代局部观测 | 集中式假设与分布式设定不符 | 明确观测是局部还是全局，且各方法一致 |

## 二、可行性处理越界

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 动作掩码按业务分数（能效、时延、公平）排序或择优 | 掩码在代替策略做业务优化 | 检查掩码只依赖约束是否满足，不依赖目标值排序 |
| 投影/修复把动作替换成"更优"的可行解 | 同上，且掩盖了策略本身的不足 | 检查修复规则是否与业务收益无关、是否只修可行性 |
| 掩码依赖策略输出之外的特权信息 | 与其他方法信息假设不一致 | 逐项列出掩码看到的量，并与基线对齐 |
| 无合法动作时的语义未定义或按目标择优兜底 | 行为不可复现，且可能偷渡优化 | 明确"无合法动作"的显式语义（等待/丢弃/降级），写进规格 |

## 三、不公平比较

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 基线只用默认超参，候选做了大范围搜索 | 差异可能来自调参预算而非方法 | 对比记录各方法的搜索范围/试验数/预算 |
| 方法特有计算或信息差异未公开 | 读者无法判断可比性 | 列出各方法的计算量、信息访问、额外模块，写进 G6 冻结单 |
| 不同方法用不同种子集合或不同场景子集 | 配对比较失效 | 检查种子列表与场景划分是否按方法一致 |
| "共同随机数"假定不成立（不同策略导致调用次数/时刻不同） | 场景不再相同，差异被外生因素污染 | 记录外生随机场景的生成方式，按场景而非按 episode 统计 |
| 候选用了额外奖励塑形/辅助损失，基线没有 | 课程化优势，违反统一目标 | 对齐训练信号公式；命中即按禁令处理 |

## 四、环境迎合

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 先看结果再删困难场景/调节负载分布 | 造有利环境 | 检查场景集合的定义时刻与变更记录 |
| 奖励权重在观察结果后调整 | 目标漂移 | 对照 `formal-design.md` 冻结的权重与代码实际值 |
| 只报告有利规模（如仅报告低负载或少量 UE） | 泛化范围被隐藏 | 检查是否覆盖冻结的规模/负载/资源范围 |

## 五、Lyapunov / 虚拟队列类（本项目主线）

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 虚拟队列初值选择有利（如全零且未说明敏感性） | 早期漂移与惩罚折衷被人为放宽 | 记录初值，做初值敏感性小实验 |
| 罚参数 V（或等价权重）只在自家方法调优 | 折衷点被单方面优化 | 各比较方法使用可比的折衷扫描预算 |
| 预算 B_C 未真正约束（事后裁剪、只统计不惩罚） | 约束形同虚设，结论不可用 | 检查违例计数/分母与约束是否进入实际决策 |
| 队列稳定性表述与 QoS 延误约束混淆 | 理论结论被夸大 | 区分"队列稳定"与"ε_M/ε_L 满足"，分别给证据 |
| 用上界/松弛结果代替实测性能 | 理论界的可达性未验证 | 上界与实测分开报告，注明差距与原因 |
| 把"通过消融"当成"理论保证成立" | 实验与理论混淆 | 理论结论只在被证明的假设下陈述 |

## 六、储能与碳强度（本项目特有问题）

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 碳强度预测器使用了未来 CI（或在整个时间窗上拟合） | 未来信息泄漏 | 检查预测器的输入时间窗与决策时刻的关系 |
| 储能被当作免费能量（充电不计能耗/成本） | 碳账失真 | 核对充放电两侧的能量与碳排放计入方式 |
| 虚拟储能队列初值/容量设置有利 | 相当于预置免罚额度 | 记录容量与初值，做敏感性说明 |
| 碳预算事后裁剪（超出部分不计入指标） | 指标被人为合法化 | 检查违例统计口径与分母 |
| 碳排放口径不一致（只算计算能耗，忽略传输/待机/冷却） | 方法间比较口径不同 | 明确并统一边界；口径变化须新版本重验 |
| 只报碳排而不报时延/违例 | 掩盖以延迟/违例换碳排 | 同时报告主次指标与约束违例率 |

## 七、评价与统计

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 把同一模型的多个 episode/时间步当作独立训练样本 | 高估样本量，区间过窄 | 明确独立样本单位=独立训练，评价重复另计 |
| 只报最佳种子的结果 | 择优报告 | 报全部种子与区间/离散度 |
| 无区间估计、无效应量、多重比较未处理 | 结论强度无支撑 | 按 G6 冻结的统计方法重算 |
| 用训练曲线平滑后截取 | 结论被美化 | 用原始日志；平滑规则须预先声明 |

## 八、可复现与运行

| 现象 | 为什么是问题 | 可复核动作 |
|---|---|---|
| 未提交改动只记 Git HEAD | 实际代码不可还原 | 记录工作区改动快照或内容哈希 |
| 依赖未锁定（只写"最新版"） | 环境不可重建 | 锁定或记录实际版本 |
| 非确定性来源未记录（cuDNN、并行、线程数） | 结果不可重放 | 记录确定性开关与容差 |
| 终态运行被重启并沿用原 run ID | 独立样本被重复计数 | 检查 run 的 `resume_of` 链与终态保护 |
| 失败/违例记录被删除 | 只保留有利证据 | 保留失败产物；聚合表引用全部纳入与排除的运行 |

## 用法建议

- **分析者**：在 G2 交建模规格前逐类自查"环境与比较设计"，把命中项写进报告的未知/待决定。
- **执行者**：在 G3/G4/G5 的验收表里，把泄漏、守恒、共同随机数三项作为必查行。
- **审查者**：用本表做审查索引，但结论必须来自实际产物与冻结规格；未检出≠不存在，未取证≠违规。
