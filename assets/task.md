任务 ID：待填写唯一 ID
角色：literature / analyst / executor / reviewer 中选一
项目根目录：真实绝对路径
主帅实际会话 ID / ownership epoch：从 control.json 核对

skill 绝对路径：当前安装的 SKILL.md
实际代理 ID：由派发回执填写；派发前未知

## 目标与验收

一个边界明确的目标；具体交付物与可观察的通过/失败条件。

## 最小输入

冻结规格、已有证据和本角色规范的绝对路径；不要附旧对话全文。

## 可读、可改与预算

- 可读材料：明确路径 / 文献原件
- 可改代码和报告：明确写集；主帅状态和 control.json 不属于角色写集
- 预算：设备、步骤/时间、并发、停止条件
- 依赖：已通过闸门和不能越过的未通过闸门
- 共同方法禁令：遵守 SKILL.md；疑似违规先回报，不能偷偷改奖励或加入教师

## 执行与阻塞处理

先核对输入和阶段；训练须由主帅登记唯一 run ID 并确认实际所有权。证据缺失或失败时保留状态，回报可复现问题，不自行扩大范围。

上下文检查绑定自己的真实代理会话 ID；绑定未知就标未知。第一次压缩后重读本任务与当前规格；80% 准备检查点，90% 或第二次压缩交回主帅，由全新代理继续。
